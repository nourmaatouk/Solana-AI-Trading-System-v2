# Backtesting Notebooks

Jupyter notebooks for historical strategy evaluation and optimization.

## Purpose

Contains notebooks for:
- Running historical simulations
- Evaluating trading strategies
- Calculating performance metrics (Sharpe ratio, max drawdown, etc.)
- Optimizing strategy parameters
- Analyzing trade-by-trade performance
- Risk analysis

## Workflow

1. Load historical data
2. Prepare features
3. Run simulation with strategy
4. Calculate metrics
5. Analyze results
6. Iterate and optimize
