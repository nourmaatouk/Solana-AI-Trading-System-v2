# Dashboard Components

Reusable React components for the trading dashboard interface.

## Purpose

Components provide:
- Chart visualizations (candlesticks, volume, correlations)
- Data tables and grids
- Control panels and forms
- Status indicators and alerts
- Modal dialogs and overlays

## Key Components

- **Heatmaps/** - SHAP explainability visualizations
- **LiveSignals/** - Real-time trading signals display
- **ShapExplainer/** - Model explainability interface
