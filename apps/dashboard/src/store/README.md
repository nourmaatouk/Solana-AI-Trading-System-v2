# State Management Store

Global state management for the React dashboard.

## Purpose

Manages:
- User authentication and session state
- Real-time market data
- Trading positions and orders
- UI state (modals, filters, sorting)
- User preferences and settings
- Cache management

## Implementation

Uses state management library (Redux, Zustand, etc.) for:
- Centralized state
- Predictable state updates
- Time-travel debugging
- Middleware and side-effects handling
