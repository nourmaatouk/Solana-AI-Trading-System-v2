# Dashboard Source Code

React application source code for the trading dashboard.

## Structure

- **components/** - Reusable UI components (charts, tables, controls)
- **hooks/** - Custom React hooks for data fetching and state logic
- **pages/** - Page components for application routes
- **store/** - Global state management

## Purpose

Contains all React components and logic for:
- Rendering the user interface
- Managing application state
- Handling user interactions
- Communicating with the API backend
