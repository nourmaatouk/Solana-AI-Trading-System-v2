# Custom React Hooks

Custom hooks for shared logic and data fetching in the dashboard.

## Purpose

Provides:
- API data fetching and caching
- WebSocket connection management
- State management utilities
- Local storage persistence
- Real-time data subscription management

## Common Hooks

- useMarketData() - Fetch and cache market data
- useWebSocket() - Establish WebSocket connections
- useTradeHistory() - Fetch and update trade history
- usePerformanceMetrics() - Retrieve performance analytics
