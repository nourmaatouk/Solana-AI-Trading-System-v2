# Dashboard

React frontend for real-time monitoring and visualization of the trading system.

## Structure

- **public/** - Static assets (index.html, favicons, manifest files)
- **src/** - React application source code
  - **components/** - Reusable React components
  - **hooks/** - Custom React hooks
  - **pages/** - Page components for routing
  - **store/** - State management (Redux, Zustand, etc.)

## Purpose

Provides traders and analysts with:
- Real-time trading activity visualization
- Performance analytics and reporting
- SHAP explainability heatmaps
- Market data visualization (candlesticks, volumes, correlations)
- Risk monitoring and alerts
- System health and status dashboard

## Key Features

- Real-time WebSocket data updates
- Interactive charts and visualizations
- Model explainability interface
- Trading history and analytics
- Responsive design
