# API Routers

API endpoint definitions organized by functional domain.

## Purpose

Routers define and implement:
- Trading endpoints (place order, cancel order, get positions)
- Data endpoints (historical prices, market data, analytics)
- Analytics endpoints (performance, attribution, risk metrics)
- System endpoints (health, status, configuration)
- Monitoring endpoints (logs, metrics, traces)

## Organization

Each router handles a specific domain:
- Trade execution and management
- Real-time market data
- Historical data and analytics
- System administration
- Monitoring and debugging
