# Docker

Docker configuration for containerizing system services.

## Purpose

Provides:
- Dockerfile for building service images
- Docker Compose for local development
- Image versioning and tagging strategy
- Registry configuration

## Services

Docker images for:
- API server
- Agent service
- Database services (TimescaleDB, Redis, ChromaDB)
- Processing services
- Model serving containers

## Build and Push

Commands for building and pushing images to container registry.
