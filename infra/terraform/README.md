# Terraform Infrastructure-as-Code

Terraform configurations for provisioning cloud infrastructure.

## Purpose

Manages:
- Cloud resource provisioning (compute, storage, networking)
- Database resources
- Security and IAM policies
- Monitoring and logging infrastructure
- VPC and network configuration

## Providers

Supports provisioning to cloud providers:
- AWS
- Google Cloud Platform
- Azure

## Modules

Organized by functional domain:
- Compute resources
- Database and storage
- Networking
- Security and IAM
- Monitoring
