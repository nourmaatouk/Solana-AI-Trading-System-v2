# Risk Management Service

Risk validation and compliance checking before trade execution.

## Purpose

Enforces:
- Position size limits
- Leverage limits
- Maximum loss limits (stops)
- Concentration limits
- Correlation-based risk limits
- Regulatory compliance

## Risk Checks

- Pre-trade validation
- Real-time P&L monitoring
- VaR calculations
- Stress testing
- Scenario analysis

## Features

- Circuit breakers for rapid market moves
- Automatic position liquidation triggers
- Risk aggregation across strategies
