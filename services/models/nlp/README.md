# NLP Models

Natural Language Processing for sentiment and market analysis.

## Purpose

Processes:
- Financial news sentiment
- Reddit sentiment analysis
- Social media trends
- Market news classification

## Models

- FinBERT for financial sentiment
- BERT for general NLP
- Custom fine-tuned models

## Output

Returns:
- Sentiment scores (bullish/bearish)
- Confidence levels
- Entity extraction (companies, coins)
- Trend detection
