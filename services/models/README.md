# AI/ML Models Service

Machine learning model implementations and inference.

## Structure

- **classification/** - Classification models
- **fusion/** - Ensemble fusion models
- **nlp/** - NLP models (FinBERT, sentiment analysis)
- **rl/** - Reinforcement learning models
- **spatial/** - Spatial/graph models
- **temporal/** - Time-series models

## Purpose

Provides:
- Model loading and inference
- Real-time signal generation
- Model versioning and deployment
- Confidence scores and uncertainty estimates

## Model Types

- **GNN** - Graph neural networks for market relationships
- **XGBoost** - Gradient boosting for classification
- **PPO** - Reinforcement learning policy
- **FinBERT** - Financial NLP
- **Temporal** - LSTM/Transformer time-series
- **Fusion** - Ensemble of multiple models
