# Packages

Shared libraries and utilities used across the system.

## Structure

- **core/** - Core type definitions and shared interfaces
- **db/** - Database clients and connections
- **utils/** - Utility functions and helpers

## Purpose

Provides:
- Shared type definitions for type safety
- Database connection pooling
- Utility functions for common tasks
- Configuration management
- Logging and monitoring

## Dependencies

Other modules depend on packages for:
- Type definitions
- Database access
- Common utilities
- Configuration
